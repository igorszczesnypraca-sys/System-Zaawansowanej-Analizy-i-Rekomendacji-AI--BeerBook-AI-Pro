#  System Zaawansowanej Analizy i Rekomendacji AI
Implementacja pełnego procesu ETL (ekstrakcja Markdown z użyciem Regex) oraz stworzenie mechanizmu automatycznej rywalizacji trzech modeli regresyjnych (Random Forest, Linear Regression, KNN) do predykcji. Wdrożenie modułu Explainable AI (XAI) do interpretacji decyzji oraz analizy eksploracyjnej (EDA) przy użyciu macierzy korelacji.

(Technologie: Python, Pandas, Scikit-Learn, Seaborn, Matplotlib, Tkinter).
